# 아트브리프 — 신뢰 매체로 보는 예술계 소식

국내외의 신뢰할 수 있는 예술 매체를 목록으로 정해 두고, 그 매체들의 최신 기사를 한곳에 모아 보여주는 사이트입니다.

## 사이트

https://woch4941-ship-it.github.io/art-brief/

GitHub Actions(`.github/workflows/update.yml`)가 하루 두 번(한국시간 오전 7시·오후 7시) 뉴스와 전시를 수집해 자동으로 배포합니다. 저장소의 Actions 탭에서 '수집 및 배포'를 골라 직접 실행할 수도 있습니다.

## 사용법 (내 컴퓨터에서)

1. `뉴스 업데이트.bat` 더블클릭 → 최신 기사를 수집하고 사이트를 엽니다.
2. 또는 터미널에서 `python collect.py` 실행 후 `site/index.html` 열기.

Python 3.9 이상만 있으면 되고, 별도 설치할 라이브러리는 없습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `sources.json` | 수집 대상 매체 목록 (매체 추가·삭제는 여기서) |
| `collect.py` | 수집기: RSS/HTML 수집 → 분야 분류 → 번역 → `site/data/` 저장 |
| `translate.py` | 해외 기사 자동 번역 (구글 번역 또는 Claude) |
| `exhibitions.py` | 국내 미술관·박물관 전시 수집 → `site/data/exhibitions.js` |
| `site/` | 정적 사이트 (index.html, style.css, app.js). 이 폴더만 그대로 웹에 올리면 됩니다 |
| `site/data/archive.json` | 최근 30일 기사 누적 보관소 (수집할 때마다 갱신) |

## 주요 이슈

첫 화면은 기사 목록이 아니라 **최근 3일 주요 이슈**입니다. 최근 3일 동안 두 곳 이상의 매체가 같은 소식을 다루면 하나의 이슈로 묶고, 보도한 매체가 많은 순서로 보여줍니다. 각 이슈를 펼치면 매체별 기사를 볼 수 있습니다.

- 묶는 기준: 제목에 같은 고유명사(인물·기관명)가 있고 내용 단어가 충분히 겹치거나, 제목 자체가 많이 겹칠 때. 잘못 묶이는 것을 막기 위해 기준을 엄격하게 잡았습니다 (`collect.py`의 `find_issues`).
- e-flux 공지는 기관별 발표라 묶기에서 제외합니다.
- 이슈 아래에는 '그 밖의 주목할 소식'(인사·시장·부고·문화유산 분야, 매체당 1건)과 '국내 소식'이 이어지고, 모든 기사는 '전체 기사' 탭에서 볼 수 있습니다.

## 전시

'전시' 탭은 국내 미술관·박물관 홈페이지에서 현재·예정 전시를 모아 보여줍니다. 뉴스 수집 때 함께 수집되며, `python exhibitions.py`로 따로 돌릴 수도 있습니다.

- 대상(국내 규모 상위 기관 중 수집 가능한 8곳): 국립현대미술관(서울·과천·덕수궁·청주), 서울시립미술관(분관 포함), 국립중앙박물관, 부산시립미술관, 대구미술관, 경기도미술관, 울산시립미술관, 전북도립미술관
- 화면: '곧 끝나는 전시'(14일 이내) / '진행 중' / '개막 예정'(120일 이내)으로 나누고, 지역·기관·검색으로 거를 수 있습니다.
- 기관 추가: `exhibitions.py`의 `SITES`에 목록 주소와 정규식을 추가합니다. 이름 있는 그룹 `url`, `title`, `start`, `end`가 필수이고 `img`, `place`, `branch`, `alt`(전체 제목)는 선택입니다.
- 어떤 기관의 수집이 실패하면 그 기관은 지난번 결과를 그대로 보여줍니다.
- 상위 15곳 중 아직 넣지 못한 곳: 리움·호암(목록 데이터가 접속 세션 필요), 광주시립(새 주소에서 빈 응답), 대전시립(접속 시간 초과), 부산현대(임시 휴관·접속 차단), 경남도립·예술의전당 한가람(자바스크립트로 그려짐), 국립아시아문화전당(배너 이미지에만 정보).

## 자동 번역

해외 기사의 제목과 요약은 수집할 때 한국어로 자동 번역됩니다. 한 번 번역한 기사는 `site/data/archive.json`에 저장해 두고 다시 번역하지 않습니다. 사이트 상단의 `번역 / 원문` 버튼으로 전환할 수 있고, 번역문 아래에 원문 제목이 작게 함께 표시됩니다.

번역 엔진은 환경 변수 `TRANSLATOR`로 고릅니다.

| 값 | 설명 |
|---|---|
| `google` (기본) | 구글 번역 공개 주소. 키·설치가 필요 없지만 비공식 경로라 언제든 막힐 수 있고, 매체명·작가명을 가끔 오역합니다 |
| `claude` | Claude API(`claude-opus-5-5`). `pip install anthropic` 후 `ANTHROPIC_API_KEY`를 설정하면 됩니다. 고유명사와 미술 용어를 더 정확히 옮깁니다. 키가 설정되어 있으면 자동으로 이 엔진을 씁니다 |
| `off` | 번역하지 않음 |

번역이 실패한 기사는 원문 그대로 보이고, 다음 수집 때 다시 번역을 시도합니다.

## 매체 선정 기준

현재 23곳(국내 6, 해외 17)이며 30곳 이내로 유지합니다. 전체 기사 탭의 기본 기간은 3일입니다.

- **예술 전문 매체만**: 편집 방침과 발행 이력을 갖춘 미술·예술 전문지, 전문 웹진, 미술계 공식 발표 채널(e-flux).
- **일반 뉴스 제외**: 통신사·종합일간지 문화면처럼 예술을 부분적으로 다루는 언론은 넣지 않습니다.
- **그 밖의 제외**: 보도자료 재가공 위주의 인터넷 매체, 블로그·커뮤니티, 갱신이 멈춘 피드.

## 매체 추가하기

`sources.json`의 `sources` 배열에 한 줄을 추가합니다.

```json
{"id": "고유id", "name": "표시 이름", "region": "국내", "lang": "ko", "kind": "전문지",
 "home": "https://홈페이지", "type": "rss", "feed": "https://RSS주소", "why": "선정 이유"}
```

- `kind`는 `전문지` / `웹진` / `공식 발표` 중 하나입니다.
- RSS가 없는 사이트는 `"type": "html"`, `"list": 목록페이지주소`, `"pattern": 정규식`으로 지정합니다. 정규식의 이름 있는 그룹으로 `url`, `title`, 선택적으로 `org`(기관명), `date`(게시일)를 뽑습니다. `url`이 주소 일부(slug)뿐이면 `"link": "/경로/{url}"`로 완성합니다. e-flux, 아트인컬처 항목을 참고하세요.

매체 목록 페이지에서 "수집 실패" 또는 "피드 갱신 중단 의심"이 보이면 해당 매체의 주소를 점검하세요.

## 참고

- 국내 매체 중 퍼블릭아트, 서울아트가이드, 예술경영지원센터, 국립현대미술관 보도자료 등은 공개 피드가 없거나 접속·구조 문제로 아직 포함하지 못했습니다.
- 기사 제목·요약의 저작권은 각 매체에 있으며, 사이트는 원문 링크로 연결합니다.
